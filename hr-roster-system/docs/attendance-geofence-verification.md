# 项目考勤与电子围栏本地验收

## 验收边界

- 仅在本地或测试环境执行，不对生产环境写入测试数据。
- 使用虚构员工和测试坐标，不记录真实账号、密码、Token 或员工定位。
- 准备同一客户下的项目 A / 项目 B，以及分别只授权一个项目的驻厂 A / 驻厂 B 账号。

## 项目权限

1. 企业管理员可分别打开项目 A 和项目 B 的日报、月报与设置。
2. 驻厂 A 只能在项目选择器中看到项目 A，直接请求项目 B 返回 403。
3. 驻厂 B 只能看到项目 B，不能查看项目 A 员工考勤。
4. 即使项目 A 和项目 B 属于同一客户，驻厂权限仍按项目隔离。
5. 薪资只读角色可读取授权范围考勤汇总，不可保存项目规则、特殊日期或围栏。

## 规则与统计

1. 为项目 A 设置上下班、午休、宽限时间、标准工时和星期工作日。
2. 增加一个特殊工作日和一个特殊休息日，确认特殊日期优先于星期规则。
3. 查看当日日报，核对应出勤、正常、迟到、早退、缺卡、旷工和围栏异常数与明细一致。
4. 查看当月汇总，确认无打卡工作日仍计入旷工，休息日不计应出勤。
5. 将测试员工从项目 A 调到项目 B，确认调项目前后记录分别保留在对应项目报表。

## 客户围栏

1. 在同一客户围栏库创建两个测试围栏，并同时关联项目 A。
2. 分别在围栏 1 内和围栏 2 内打卡，确认任一围栏命中均返回 `INSIDE`。
3. 在围栏外、定位精度不足和定位失败时确认仍允许打卡，但进入当前项目异常审核。
4. 尝试把其他客户围栏关联项目 A，确认服务端拒绝。
5. 仅有 `attendance:view` 时页面不显示经纬度；拥有 `attendance:manage` 时才能查看坐标和修改设置。
